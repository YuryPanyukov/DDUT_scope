## Задача 4 — управление столбцами во всём проекте (2026-09-27)

- Новый модуль `evaluation_app/ui/column_controls.py`:
  `enable_column_controls(view, on_columns_changed=None)` — делает столбцы перетаскиваемыми
  (`setSectionsMovable`) и изменяемыми по ширине, вешает меню ПКМ; `make_columns_interactive`
  считает ширины по содержимому (`resizeSections`) и переводит все столбцы в `Interactive`;
  `build_header_menu(view, index)` собирает меню «Скрыть столбец «…»» + «Показать все скрытые
  столбцы» (пункты связаны с действием — тесты зовут `action.trigger()` без показа меню).
- Важные находки: ширины считаются только при показе вида (до `show` геометрия не разложена) —
  `_InteractiveOnShow` (eventFilter, игнорируется vulture как `closeEvent`) финализирует на
  первом Show, если столбцы ещё не все `Interactive`; от ПКМ `sectionClicked` НЕ срабатывает
  (проверено sendEvent), поэтому сортировка правой кнопкой не запускается.
- Подключено к: сводной таблице, матрице `DirectionView`, `mapping_table`/`preview_table`/`grid`
  диалогов импорта. В `DirectionView` скрытые столбцы хранятся по названию
  (`_hidden_columns`) и применяются заново в `_apply_headers` — скрытие переживает сортировку
  и смену преподавателя; при неизменных заголовках `_apply_headers` не трогает ширины.
- `pyproject.toml`: `eventFilter` добавлен в `ignore_names` vulture (вызывается только Qt).
- Тесты: `test_column_controls_manual_layout_and_menu`, `test_column_menu_hides_and_restores_columns`,
  `test_direction_view_hidden_column_survives_rebuild`; README (п. 5 «Столбцы») обновлён.

## Что было сделано

### Задача 1 — формула ИТОГО пропускает столбец «за вход в систему»

Во всех реальных файлах преподавателей колонка `ИТОГО` — это `=SUM(C:AF)`, первый столбец
(«за вход в систему», максимум 30) в неё не входит, из-за чего итог ученика меньше суммы ячеек.

- `evaluation_app/utils/validators.py`: программный признак служебного столбца входа —
  `LOGIN_COLUMN_RE` + `is_login_column(label)` (шаблон `вход\s+в\s+систему`).
- `evaluation_app/services/excel_parser.py`: `HeaderLayout.login_column` заполняется в
  `detect_layout` и `_layout_from_overrides` через `_detect_login_column`.
- `_parse_criteria_rows`: если файловое ИТОГО равно сумме критериев (формула «забыла» столбец),
  баллы столбца входа добавляются к итогу отдельной оценкой «за вход в систему» + предупреждение
  «формула ИТОГО не учитывает столбец …». Если файловое ИТОГО уже учитывает столбец — баллы
  добавляются молча (без предупреждения). Прочие расхождения — прежняя логика (значение из
  файла + предупреждение). Столбец читается только при наличии колонки ИТОГО: без неё
  формулы, которая могла бы его пропустить, в файле нет.

### Задача 2 — ученики с нулём баллов

- Режим «критерии»: строка с корректным ФИО **всегда** даёт запись; если критериев нет и
  ИТОГО 0/пусто — добавляется одна оценка с 0 баллов, `rows_parsed` считается и для нулевых строк.
- Режим «строки»: пустая ячейка баллов (None/пустая строка) даёт 0 баллов + предупреждение
  «не указано значение баллов — учтено 0» (туда же попадает формула без кэша Excel);
  текст («нет данных») по-прежнему пропускается с предупреждением.
